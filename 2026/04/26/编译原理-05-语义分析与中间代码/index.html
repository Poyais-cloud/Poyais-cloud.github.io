05 — 语义分析与中间代码

上一节 04 - LR 分析 | 返回 00 - 索引 | 下一节 06 - 综合扩展题

1. 语法制导翻译与属性文法

关键概念速记

  • 综合属性：节点的属性值由其子节点计算（自底向上）
  • 继承属性：节点的属性值由其父节点或兄弟节点计算（自顶向下或横向）
  • S-属性文法：仅含综合属性 → 可在 LR 分析时同步计算
  • L-属性文法：综合属性 + 限定形式的继承属性 → 可在 LL 或 LR 分析时计算
  • 语义动作：写在产生式右部某位置的代码片段 {...}，分析到该位置就执行

真题

[A·二·8]（3 分）填空

综合属性的值由 ____ 计算得到，继承属性的值由 ____ 计算得到。

答案：子节点（自底向上）；父节点或兄弟节点（自顶向下或横向）

[C·一·6]（3 分）填空

一个属性文法仅含综合属性时，称为 ____ 属性文法。

答案：S-属性文法

2. 三地址码与四元组

三地址码的常见形式

  • 赋值：x := y op z，x := op y（一元），x := y
  • 跳转：goto L，if x relop y goto L
  • 过程调用：param x、call p, n、return y
  • 数组：x := y[i]，x[i] := y
  • 指针：x := &y，x := *y，*x := y

四元组表示

四元组形如 $(\text{op}, \text{arg}_1, \text{arg}_2, \text{result})$。

三地址码 四元组
x := y + z (+, y, z, x)
x := -y (uminus, y, _, x)
x := y (:=, y, _, x)
goto L (goto, _, _, L)
if x < y goto L (j<, x, y, L)
param x (param, x, _, _)
call p, 2 (call, p, 2, _)

SOP：表达式翻译为四元组

Note 表达式生成四元组流程

  1. 递归遍历语法树（自底向上）
  2. 每个内部节点生成一个临时变量 $t_i$
  3. 每个运算生成一条四元组，结果放入 $t_i$
  4. 整棵树的最终结果是根节点对应的临时变量

真题

[A·六·19]（10 分）翻译为四元组

把表达式 $A := B + C * (D - E)$ 翻译成四元组序列。

解答

按运算优先级和结合性，自底向上：

  1. $t_1 := D - E$ → $(-, D, E, t_1)$
  2. $t_2 := C * t_1$ → $(*, C, t_1, t_2)$
  3. $t_3 := B + t_2$ → $(+, B, t_2, t_3)$
  4. $A := t_3$ → $(:=, t_3, _, A)$

四元组序列：

Tip 四元组编号通常从 100 开始（约定俗成，留出位置给可能的库代码或入口跳转）。但具体题目按题面要求；不指定就从任意编号起，自洽即可。

3. 布尔表达式的短路翻译（重点）

核心思想

短路求值：A and B，若 A 为假则不算 B；A or B，若 A 为真则不算 B。

实现：真假出口（truelist / falselist）+ 回填（backpatch）。

关键属性

每个布尔表达式 $E$ 维护两条链：

  • $E.\text{truelist}$：$E$ 为真时跳转的四元组列表（待回填目标地址）
  • $E.\text{falselist}$：$E$ 为假时跳转的四元组列表

关键操作

Note 三个核心动作

  1. makelist(i)：创建只含四元组 $i$ 的链表
  2. merge(p, q)：合并两条链表
  3. backpatch(p, addr)：把链表 $p$ 中所有四元组的跳转目标改为 $addr$

翻译规则速记

产生式 语义动作
$E \to E_1 \text{ or } M\ E_2$ $\text{backpatch}(E_1.\text{falselist}, M.\text{quad})$;
$E.\text{truelist} = \text{merge}(E_1.\text{truelist}, E_2.\text{truelist})$;
$E.\text{falselist} = E_2.\text{falselist}$
$E \to E_1 \text{ and } M\ E_2$ $\text{backpatch}(E_1.\text{truelist}, M.\text{quad})$;
$E.\text{truelist} = E_2.\text{truelist}$;
$E.\text{falselist} = \text{merge}(E_1.\text{falselist}, E_2.\text{falselist})$
$E \to \text{not } E_1$ $E.\text{truelist} = E_1.\text{falselist}$;
$E.\text{falselist} = E_1.\text{truelist}$
$E \to (E_1)$ $E.\text{truelist} = E_1.\text{truelist}$;
$E.\text{falselist} = E_1.\text{falselist}$
$E \to a\ \text{relop}\ b$ 生成 $(j,\text{relop}, a, b, ?)$ 和 $(j, _, _, ?)$ 两条四元组；
$E.\text{truelist} = \text{makelist}(\text{nextquad})$；
$E.\text{falselist} = \text{makelist}(\text{nextquad}+1)$
$M \to \varepsilon$ $M.\text{quad} = \text{nextquad}$（标记当前位置）

SOP：布尔表达式翻译

Note 翻译流程

  1. 从左到右处理输入，每识别一个比较表达式 $a,\text{relop},b$，立刻产生两条四元组（条件跳和无条件跳，目标暂时为 ?）
  2. 遇到 or：左操作数若为假需跳到右操作数起点，回填左操作数的 falselist
  3. 遇到 and：左操作数若为真需跳到右操作数起点，回填左操作数的 truelist
  4. 遇到 not：交换 truelist 与 falselist
  5. 整体翻译完后：将整棵表达式的 truelist 回填到”为真时去的位置”，falselist 同理

真题

[D·四·18]（15 分）布尔表达式翻译

把布尔表达式 $a < b\ \text{or}\ c < d\ \text{and}\ e < f$ 翻译为四元组。

解答

按 and 优先于 or 的约定，结构为：$(a<b)\ \text{or}\ ((c<d)\ \text{and}\ (e<f))$。

设四元组从 100 开始。

逐步翻译：

读 $a < b$：

$E_1.\text{truelist} = {100}$，$E_1.\text{falselist} = {101}$。

读 or，记 $M_1.\text{quad} = 102$（$E_1$ 为假后右操作数起点）。

读 $c < d$：

$E_2.\text{truelist} = {102}$，$E_2.\text{falselist} = {103}$。

读 and，记 $M_2.\text{quad} = 104$（$E_2$ 为真后右操作数起点）。

读 $e < f$：

$E_3.\text{truelist} = {104}$，$E_3.\text{falselist} = {105}$。

应用 and 规则（处理 $E_2\ \text{and}\ E_3$，记结果为 $E_{23}$）：

  • $\text{backpatch}(E_2.\text{truelist}, M_2.\text{quad}=104)$ → 四元组 (102) 的目标改为 104
  • $E_{23}.\text{truelist} = E_3.\text{truelist} = {104}$
  • $E_{23}.\text{falselist} = \text{merge}(E_2.\text{falselist}, E_3.\text{falselist}) = {103, 105}$

应用 or 规则（处理 $E_1\ \text{or}\ E_{23}$，记结果为 $E$）：

  • $\text{backpatch}(E_1.\text{falselist}, M_1.\text{quad}=102)$ → 四元组 (101) 的目标改为 102
  • $E.\text{truelist} = \text{merge}(E_1.\text{truelist}, E_{23}.\text{truelist}) = {100, 104}$
  • $E.\text{falselist} = E_{23}.\text{falselist} = {103, 105}$

最终四元组（部分目标已回填，整体真假出口待外部回填）：

整体表达式属性：

$$
\boxed{
\begin{aligned}
E.\text{truelist} &= {100, 104} \
E.\text{falselist} &= {103, 105}
\end{aligned}
}
$$

Tip 四元组中 (102) 的目标我已写为 104（已回填）。考试答题时两种做法均可：① 写明回填动作”将 (102) 目标回填为 104”，目标处保留原样；② 直接把回填后的目标写在四元组里。第二种更简洁。

Warning 易错点：or 时回填的是左操作数的 falselist（左假才走右），and 时回填的是左操作数的 truelist（左真才走右）。”假走或、真走与”。

[E·四·18]（15 分）含 if-then-else 的翻译

把语句 if a < b then x := 1 else x := 2 翻译为四元组。

解答

文法骨架：$S \to \text{if } E \text{ then } M_1 S_1 N \text{ else } M_2 S_2$

其中 $N \to \varepsilon$（动作：在 then 分支末尾生成一条无条件跳转，跳过 else 分支）。

设从 100 起。

翻译 $E$（即 $a < b$）：

$E.\text{truelist} = {100}$，$E.\text{falselist} = {101}$。

$M_1.\text{quad} = 102$（then 分支起点）。

翻译 $S_1$（即 $x := 1$）：

$N$ 动作：先记 $N.\text{nextlist} = \text{makelist}(103)$，再生成 (103)：

$M_2.\text{quad} = 104$（else 分支起点）。

翻译 $S_2$（即 $x := 2$）：

回填动作：

  • $\text{backpatch}(E.\text{truelist}={100}, M_1.\text{quad}=102)$
  • $\text{backpatch}(E.\text{falselist}={101}, M_2.\text{quad}=104)$
  • $S.\text{nextlist} = N.\text{nextlist} = {103}$（$S$ 整体执行完后，回填 (103) 到下一条语句的位置）

最终四元组：

Tip if-then-else 的关键三步：

  1. 翻译 E 后开两个分支起点（$M_1$、$M_2$）
  2. then 分支末尾插一条无条件跳（$N$ 节点的 nextlist），跳过 else
  3. 回填 E 的真假出口到两个起点

4. while 循环翻译

翻译规则

文法：$S \to \text{while } M_1 E \text{ do } M_2 S_1$

语义动作：

  • $\text{backpatch}(S_1.\text{nextlist}, M_1.\text{quad})$（循环体执行完跳回判断）
  • $\text{backpatch}(E.\text{truelist}, M_2.\text{quad})$（条件真进入循环体）
  • $S.\text{nextlist} = E.\text{falselist}$（条件假退出循环）
  • 生成 $(j, _, _, M_1.\text{quad})$（循环体末尾跳回判断）

真题

[C·四·17]（15 分）while 翻译

把 while a < b do x := x + 1 翻译为四元组。

解答

设从 100 起。

$M_1.\text{quad} = 100$（循环条件起点）。

翻译 $E$（$a < b$）：

$E.\text{truelist} = {100}$，$E.\text{falselist} = {101}$。

$M_2.\text{quad} = 102$（循环体起点）。

翻译 $S_1$（$x := x + 1$）：

循环回跳：

回填：

  • $\text{backpatch}(E.\text{truelist}={100}, 102)$ → (100) 目标改为 102
  • $\text{backpatch}(S_1.\text{nextlist}, M_1.\text{quad})$：$S_1$ 是普通赋值，nextlist 为空，无需回填
  • $S.\text{nextlist} = E.\text{falselist} = {101}$（外部回填）

最终四元组：

Tip while 循环的”骨架结构”——条件四元组在前、循环体四元组在后、最后一条无条件跳回条件起点——记住这个模式直接套。

5. 数组元素引用的翻译

翻译思路

一维数组 $A[i]$（每元素 $w$ 字节，基址 $\text{base}_A$）：

  • 偏移量 $= i \cdot w$
  • 地址 $= \text{base}_A + i \cdot w$

二维数组 $A[i][j]$（行优先，每行 $n_2$ 元素，每元素 $w$ 字节）：

  • 偏移量 $= (i \cdot n_2 + j) \cdot w$

真题

[D·二·12]（5 分）填空

一维数组 $A[i]$，每个元素 $w$ 字节，数组首地址为 $a_0$，则 $A[i]$ 的地址为 ____。

答案：$a_0 + i \cdot w$

[E·二·13]（5 分）填空

二维数组 $A[i][j]$，按行优先存储，每行 $n$ 个元素，每个元素 $w$ 字节，首地址 $a_0$。$A[i][j]$ 的地址为 ____。

答案：$a_0 + (i \cdot n + j) \cdot w$

6. 类型检查

概念

  • 类型系统：定义合法表达式类型组合的规则
  • 静态类型检查：编译期完成（C/Java）
  • 动态类型检查：运行期完成（Python/JS）
  • 类型相容：可直接运算或赋值（如 int + int 合法）
  • 类型转换：隐式转换（int → float）vs 显式强制类型转换

真题

[A·三·15]（5 分）简答

简述静态类型检查与动态类型检查的区别。

答案要点

维度 静态类型检查 动态类型检查
时机 编译期 运行期
代表语言 C、Java、Pascal Python、JavaScript
优点 错误早发现；运行时无开销 灵活；变量类型可变
缺点 灵活性差；要写更多类型声明 错误延迟到运行；运行有开销
典型错误 编译报错”类型不匹配” 运行抛 TypeError
