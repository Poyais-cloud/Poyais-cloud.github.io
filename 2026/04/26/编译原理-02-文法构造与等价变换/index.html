02 — 文法构造与等价变换

上一节 01 - 词法分析 | 返回 00 - 索引 | 下一节 03 - 自顶向下分析

1. 上下文无关文法基础概念

关键定义速记

  • 文法 $G = (V_N, V_T, P, S)$：非终结符集、终结符集、产生式集、开始符号
  • 句子：从 $S$ 出发能推导出的、全由终结符组成的串
  • 句型：从 $S$ 出发能推导出的串（可含非终结符）
  • 最左推导：每步替换最左边的非终结符
  • 最右推导（规范推导）：每步替换最右边的非终结符
  • 二义性文法：存在某个句子有两棵不同的语法树（或等价地，两种不同的最左推导）

真题

[A·一·1]（3 分）单选

设文法 $G$ 的开始符号为 $S$，下列关于句子的说法正确的是（ ）
A. 由 $S$ 出发推导出的任意串都是句子
B. 由 $S$ 出发推导出的全由终结符组成的串才是句子
C. 句子可以包含非终结符
D. 句子和句型是同一概念

解答：答案 B。句型可含非终结符，句子是句型的子集（仅含终结符的句型）。

[B·一·1]（3 分）填空

文法 $G[S]$ 的句子是指 ____ 出发推导出的、由 ____ 组成的串。

答案：从开始符号 $S$；终结符

2. 设计上下文无关文法（构造文法描述给定语言）

SOP

Note 给一个语言、写一个文法

  1. 观察语言结构：找出”重复结构”、”配对结构”、”递归结构”
  2. 设计核心非终结符：每个递归/重复结构对应一个非终结符
  3. 写产生式：
    • 递归（左递归或右递归）描述重复
    • 中心嵌套结构（如 $a^n b a^n$）必须用非终结符两侧同时扩展
    • 终止条件用 ε 或基本终结符串
  4. 验证：推导几个典型串（含最短串、长串、边界串）看是否覆盖
  5. 检查多余：能否推出不在语言中的串？若能，文法过宽，要修正

经典模板速记

语言 文法
$a^n b^n$（$n \ge 1$） $S \to aSb \mid ab$
$a^n b^n$（$n \ge 0$） $S \to aSb \mid \varepsilon$
$a^n b a^n$（$n \ge 0$） $S \to aSa \mid b$
$a^n b^m$（$n,m \ge 0$） $S \to AB$，$A \to aA \mid \varepsilon$，$B \to bB \mid \varepsilon$
${a^n b^n c^m}$ $S \to AB$，$A \to aAb \mid \varepsilon$，$B \to cB \mid \varepsilon$
偶数个 a 的串 $S \to aSa \mid bSb \mid \varepsilon$（仅 a,b 时还需调整）
回文串（${a,b}$ 上） $S \to aSa \mid bSb \mid a \mid b \mid \varepsilon$

Tip 中心嵌套 vs 左/右递归：$a^n b a^n$ 必须写成 $S\to aSa$（中心嵌套）才能保证两侧 a 数相等；写 $S\to Sa\mid aS\mid b$ 是错的（会推出两侧 a 数不等的串）。

真题

[B·四·17]（10 分）构造文法

写出能描述语言 $L = {a^n b a^n \mid n \ge 0}$ 的上下文无关文法。

解答

按”中心嵌套”模板：

$$
\boxed{,S \to aSa \mid b,}
$$

验证：

  • $n=0$：$S \Rightarrow b$ ✓
  • $n=1$：$S \Rightarrow aSa \Rightarrow aba$ ✓
  • $n=2$：$S \Rightarrow aSa \Rightarrow aaSaa \Rightarrow aabaa$ ✓
  • 不能推出 $n$ 不等的串（每次扩展两侧同步加 $a$）✓

[C·四·17]（10 分）构造文法

写出描述语言 $L = {a^n b^n c^m \mid n \ge 1, m \ge 0}$ 的文法。

解答

分两块：$a^nb^n$ 部分嵌套，$c^m$ 部分独立连接。

$$
\boxed{;S \to AB,\quad A \to aAb \mid ab,\quad B \to cB \mid \varepsilon;}
$$

验证：

  • $n=1,m=0$：$S\Rightarrow AB \Rightarrow ab,B \Rightarrow ab,\varepsilon = ab$ ✓
  • $n=2,m=1$：$S \Rightarrow AB \Rightarrow aAbB \Rightarrow aabbB \Rightarrow aabbcB \Rightarrow aabbc$ ✓

Tip 只要语言能拆成”独立的两块连接”，就用 $S\to AB$ 把两个子文法粘起来，每块各管自己。

[D·四·17]（10 分）构造文法

写出文法描述语言 $L = {(ab)^n (cd)^m \mid n \ge 1, m \ge 1}$。

解答

$$
\boxed{;S \to AB,\quad A \to abA \mid ab,\quad B \to cdB \mid cd;}
$$

验证：

  • $n=m=1$：$S\Rightarrow AB \Rightarrow ab, cd$ ✓
  • $n=2,m=1$：$S\Rightarrow AB \Rightarrow abA,B \Rightarrow abab, cd$ ✓

[E·四·17]（10 分）构造文法

写出文法描述语言 $L = {a^i b^j \mid i > j \ge 0}$。

解答

策略：先生成 $a^j b^j$（嵌套），再在前面加至少一个额外的 a。

$$
\boxed{;S \to aS \mid aA,\quad A \to aAb \mid \varepsilon;}
$$

含义：

  • $A$ 推出 $a^j b^j$（$j\ge 0$）
  • $S$ 在前面加任意正个 a：$S \Rightarrow^* a^k A$（$k\ge 1$）$\Rightarrow^* a^{k+j}b^j$
  • 总数 $i = k + j > j$，正好满足 $i > j$ ✓

验证：

  • $i=1,j=0$：$S\Rightarrow aA \Rightarrow a\varepsilon = a$ ✓
  • $i=3,j=1$：$S\Rightarrow aS \Rightarrow aaA \Rightarrow aaaAb \Rightarrow aaab$ ✓

Warning “$i > j$”这种非对称约束最容易写错。技巧：用嵌套生成对称部分（$a^jb^j$），再在外侧补不对称的差。

3. 消除左递归

SOP

Note 消除左递归（直接 + 间接）

  1. 判别：
    • 直接左递归：$A \to A\alpha$
    • 间接左递归：$A \to B\alpha$ 且 $B \Rightarrow^+ A\beta$
  2. 消除间接左递归：先把所有非终结符按某顺序 $A_1, A_2, \ldots, A_n$ 排好；
    • 对 $i$ 从 1 到 $n$：对 $j$ 从 1 到 $i-1$，把 $A_i \to A_j\gamma$ 中的 $A_j$ 代入展开
    • 这样所有产生式只剩直接左递归形式
  3. 消除直接左递归：
    • 把 $A$ 的产生式写成 $A \to A\alpha_1 \mid \cdots \mid A\alpha_m \mid \beta_1 \mid \cdots \mid \beta_n$（$\beta_i$ 不以 $A$ 开头）
    • 替换为：$A \to \beta_1 A’ \mid \cdots \mid \beta_n A’$，$A’ \to \alpha_1 A’ \mid \cdots \mid \alpha_m A’ \mid \varepsilon$

真题

[A·四·17]（10 分）消左递归

消除以下文法的左递归：
$E \to E + T \mid T$
$T \to T * F \mid F$
$F \to (E) \mid id$

解答

直接对 $E$、$T$ 分别套公式：

$E$ 部分：$\alpha = +T$，$\beta = T$
$$E \to T E’,\quad E’ \to +T E’ \mid \varepsilon$$

$T$ 部分：$\alpha = *F$，$\beta = F$
$$T \to F T’,\quad T’ \to *F T’ \mid \varepsilon$$

$F$ 无左递归保留。

最终文法：
$$
\boxed{
\begin{aligned}
E &\to TE’ \
E’ &\to +TE’ \mid \varepsilon \
T &\to FT’ \
T’ &\to *FT’ \mid \varepsilon \
F &\to (E) \mid \text{id}
\end{aligned}
}
$$

Tip 这就是经典表达式文法（算术四则运算）的”消左递归后”标准形式，闭着眼也要写得出来。是 LL(1) 文法常考的起点。

[C·五·18]（10 分）综合

消除以下文法左递归后求 FIRST 和 FOLLOW（FIRST/FOLLOW 见 03 文件）：
$S \to Sa \mid b$
$A \to Sc \mid d$

解答（仅做消左递归部分）

$S$ 直接左递归：
$$S \to bS’,\quad S’ \to aS’ \mid \varepsilon$$

$A$ 中含 $S$，但 $A$ 自身不是左递归（$A \to Sc$ 中 $S$ 不能推出 $A\beta$ 形式，$A$ 不出现在 $S$ 的产生式右部）。所以 $A$ 不是间接左递归。

最终文法：
$$
\boxed{
\begin{aligned}
S &\to bS’ \
S’ &\to aS’ \mid \varepsilon \
A &\to Sc \mid d
\end{aligned}
}
$$

4. 提取左公因子

SOP

Note 提左公因子流程

  1. 找最长公共前缀：对同一非终结符的多个候选式 $A \to \alpha\beta_1 \mid \alpha\beta_2 \mid \cdots \mid \gamma$
  2. 改写：
    • $A \to \alpha A’ \mid \gamma$
    • $A’ \to \beta_1 \mid \beta_2 \mid \cdots$
  3. 若某 $\beta_i$ 为空：$A’$ 中加 $\varepsilon$ 候选式
  4. 递归提取：新生成的 $A’$ 可能还有公因子，继续提

真题

[B·五·18]（10 分）提左公因子

对文法 $S \to aAb \mid aBc \mid d$，提取左公因子。

解答

$S$ 的两个候选式 $aAb$、$aBc$ 共有前缀 a：

$$
\boxed{
\begin{aligned}
S &\to a S’ \mid d \
S’ &\to Ab \mid Bc
\end{aligned}
}
$$

Tip 注意提完左公因子后新非终结符 $S’$ 自身要检查是否还有左公因子或左递归。本题 $S’ \to Ab \mid Bc$ 干净。

[D·五·18]（10 分）综合改造

对文法 $E \to E + E \mid E * E \mid (E) \mid \text{id}$，先消除左递归再提左公因子。

解答

Step 1：消左递归

$E \to E+E \mid E*E \mid (E) \mid \text{id}$
$\alpha_1 = +E$，$\alpha_2 = *E$，$\beta_1 = (E)$，$\beta_2 = \text{id}$

$$
\begin{aligned}
E &\to (E)E’ \mid \text{id},E’ \
E’ &\to +EE’ \mid *EE’ \mid \varepsilon
\end{aligned}
$$

Step 2：检查左公因子

$E$ 的两条候选式 $(E)E’$、$\text{id},E’$：以 ( 和 id 开头，无公因子，已是 LL(1) 友好形式（前缀完全不同）。

$E’$ 的候选式 $+EE’$、$*EE’$：以 + 和 * 开头，无公因子。

最终文法：

$$
\boxed{
\begin{aligned}
E &\to (E)E’ \mid \text{id},E’ \
E’ &\to +EE’ \mid *EE’ \mid \varepsilon
\end{aligned}
}
$$

Warning 这个文法仍然二义（$E + E * E$ 有两种解析），但消左递归不解决二义性。要彻底消二义需引入优先级层次（即标准的 $E\to T \mid E+T$ 那一套）。消左递归 ≠ 消二义性，是常见混淆点。

5. 二义性文法的判定与改写

SOP

Note 判定二义性

  1. 找一个句子有两棵语法树：找到即证毕（充分条件）
  2. 典型二义来源：
    • 运算符无优先级 / 无结合律：$E \to E+E \mid E*E$
    • 悬挂 else：$S \to \text{if } b\text{ then } S \mid \text{if } b \text{ then } S \text{ else } S$
  3. 改写策略：
    • 引入层次（优先级）：$E \to E+T \mid T$，$T \to T*F \mid F$
    • 强制结合方向：左结合用左递归 $E \to E+T$，右结合用右递归 $E \to T+E$
    • 悬挂 else：规定 else 与最近的 if 配对，引入”匹配的”和”未匹配的”两类语句

真题

[E·一·5]（3 分）单选

关于二义性文法，下列说法正确的是（ ）
A. 任何二义性文法都可改写为非二义性等价文法
B. 二义性文法不能描述程序设计语言
C. 一个语言对应的所有文法都是二义的，则该语言是固有二义的
D. 二义性可由消左递归消除

解答

  • A ✗ 存在固有二义语言（如 ${a^ib^jc^k \mid i=j \text{ or } j=k}$），其任何文法都二义
  • B ✗ C 语言的某些子集就是二义文法描述（dangling else 问题），可以用规则规避
  • C ✓ 这是固有二义语言的定义
  • D ✗ 消左递归是结构变换，不改变语言能力，与二义性独立
  • 答案 C
