01 — 词法分析

上一节 00 - 索引 | 返回 00 - 索引 | 下一节 02 - 文法构造与等价变换

1. 正则表达式与正则集

SOP

Note 给定正则式描述其语言（或反向构造）的 SOP

  1. 拆解算子优先级：闭包 * > 连接 > 选择 |
  2. 逐层翻译：从最外层算子开始，把每一段翻译成自然语言或集合表达
  3. 写出几个具体串验证：取最短串、典型串、边界串各一个，看是否在语言中
  4. 注意 ε：闭包 $A^*$ 包含空串，$A^+$ 不包含空串

核心结果速记

  • $a^*$ = ${\varepsilon, a, aa, aaa, \ldots}$
  • $(a|b)^$ = ${a,b}^$ = 所有由 a、b 组成的串（含空串）
  • $a(a|b)^*$ = 以 a 开头、后跟任意 a/b 串
  • $(ab)^*$ = ${\varepsilon, ab, abab, \ldots}$
  • 区分 $a^b^$ 与 $(ab)^*$：前者是”先若干 a 再若干 b”，后者是”ab 段重复”

真题

[A·二·11]（3 分）填空

正则表达式 $a(a|b)^*a$ 描述的字符串集合是 ____。

解答

  • 首尾必为 a
  • 中间为 (a|b)* —— 任意长度（含 0 长）的 a 和 b 串
  • 答案：以 a 开头、以 a 结尾，中间由任意 a 和 b 组成的字符串集合（包含 aa，因为中间可为空串）

Tip 正则结果”包不包含最短串”是常考点：$a(a|b)^*a$ 的最短串是 aa，不是 a。

2. 有限自动机（DFA / NFA）

SOP：构造识别某语言的 DFA

Note 构造 DFA 的标准流程

  1. 明确接受语言：写出语言的精确描述（用集合或自然语言）
  2. 设计状态含义：每个状态代表”已读入串的某种特征”（如”已读偶数个 a”、”上一字符是 b”）
  3. 画状态转移：对每个状态、每个输入字符，定义唯一的下一状态（DFA 必须确定且完备）
  4. 标注终态：所有”读入串属于语言”的状态设为终态
  5. 验证：跑几个串（含边界串、反例串）看是否被正确接受/拒绝

SOP：NFA 转 DFA（子集构造法）

Note 子集构造法

  1. 求初态闭包 $\varepsilon\text{-closure}(s_0)$ 作为 DFA 初态
  2. 对当前 DFA 状态 $T$ 和每个输入字符 $a$：
    • 计算 $\text{move}(T, a)$（不含 ε）
    • 求 $U = \varepsilon\text{-closure}(\text{move}(T,a))$
    • 若 $U$ 是新状态，加入工作表
  3. 重复直到没有新状态
  4. 含原 NFA 终态的 DFA 状态都设为终态

SOP：DFA 最小化

Note 划分法

  1. 初始划分：终态集 $F$ 与非终态集 $Q\setminus F$
  2. 对每个划分块 $P$ 和每个输入字符 $a$：
    • 若 $P$ 中状态对 $a$ 的转移落入不同块 → 拆分 $P$
  3. 重复到无可分
  4. 每个等价块缩成一个状态

真题

[A·一·4]（3 分）单选

关于 DFA 与 NFA，下列说法错误的是（ ）
A. NFA 允许 ε 转移 B. DFA 是 NFA 的特例
C. NFA 识别的语言比 DFA 更广 D. 任意 NFA 可转为等价 DFA

解答

  • A ✓ NFA 可以有 ε 转移
  • B ✓ DFA 是确定的 NFA
  • C ✗ NFA 与 DFA 识别能力等价，都识别正则语言
  • D ✓ 子集构造法保证可转换
  • 答案 C

Warning “识别能力相同 vs 简洁度不同”是常见迷惑点：NFA 写起来更简洁，但识别的语言类完全相同。

[B·一·5]（3 分）填空

NFA 转换为等价 DFA 的算法名称是 ____。

答案：子集构造法（subset construction）

3. 词法程序与单词识别

SOP

Note 设计词法分析程序的思路

  1. 列出单词种类：标识符、关键字、数字、运算符、界符等
  2. 为每类设计正则模式：如标识符 letter(letter|digit)*
  3. 合并为一个 NFA：用 ε 转移连接各模式的起始
  4. NFA → DFA：子集构造法
  5. DFA 最小化：减少状态
  6. 生成代码：用 switch-case 或表驱动实现状态转移

真题

[B·一·3]（3 分）填空

词法分析的任务是从源程序中识别出 ____。

答案：单词（token，记号）

[C·三·15]（5 分）简答

简述词法分析的主要功能。

答案要点

  1. 输入：源程序的字符流
  2. 输出：单词序列（token stream），每个单词形如 <种别码, 属性值>
  3. 附加任务：
    • 滤掉空白、注释
    • 处理预编译指令
    • 报告词法错误（非法字符等）
    • 维护源程序行号（供后续报错使用）
  4. 与语法分析的关系：词法分析是语法分析的预处理，把字符流抽象为单词流，简化后续处理

4. 正则表达式 → NFA（Thompson 构造）

SOP

Note Thompson 构造的三类基本规则

  1. 基本符号 $a$：两个状态 $s_1 \xrightarrow{a} s_2$
  2. 连接 $AB$：$A$ 的终态用 ε 连到 $B$ 的初态
  3. 选择 $A|B$：新增初态用 ε 分别连到 $A$、$B$ 的初态；$A$、$B$ 的终态用 ε 连到新终态
  4. 闭包 $A^*$：新增初态和终态；
    • 初态用 ε 连到 $A$ 的初态（开始一次匹配）
    • 初态用 ε 连到新终态（匹配 0 次）
    • $A$ 的终态用 ε 连回 $A$ 的初态（多次重复）
    • $A$ 的终态用 ε 连到新终态（结束）

真题

[D·三·15]（6 分）构造

用 Thompson 构造法把正则表达式 $(a|b)^*abb$ 转为 NFA。

解答

记构造步骤：

Step 1：基本 NFA

  • $N_a$：$0 \xrightarrow{a} 1$
  • $N_b$：$2 \xrightarrow{b} 3$

Step 2：$a|b$
新增初态 4、终态 5；4 ε→ 0，4 ε→ 2，1 ε→ 5，3 ε→ 5。

Step 3：$(a|b)^*$
新增初态 6、终态 7；6 ε→ 4，6 ε→ 7，5 ε→ 4（回环），5 ε→ 7。

Step 4：与 abb 串接

  • 在 7 之后接 $a$ 转移到 8（即 $7 \xrightarrow{a} 8$，注意此时不再用 ε 连到 a 的子 NFA 初态，因为是连接运算可直接合并端点）
  • $8 \xrightarrow{b} 9$
  • $9 \xrightarrow{b} 10$（10 为最终终态）

最终 NFA 状态集：${4,5,6,7,8,9,10}$（化简表示，初态 6，终态 10）

Tip 实考时画图比文字描述清晰太多。重点呈现：初态、终态、ε 转移、字符转移四类边。

5. NFA → DFA → 最小化（综合题）

真题

[E·五·19]（10 分）综合

给定正则式 $(a|b)^*abb$，要求：(1) 用 Thompson 法构造 NFA；(2) 用子集构造法转 DFA；(3) 最小化 DFA。

解答

(1) NFA：见 [D·三·15] 的构造结果（同一正则式，结果相同）。

(2) NFA → DFA

设 NFA 的初态为 $s_0 = 6$，沿用上题状态编号（初态 6、终态 10）。

求 $\varepsilon\text{-closure}({6}) = {6, 4, 7, 0, 2}$ —— 记为 $A$（含初态、所有 ε 可达点）。

DFA 状态 NFA 状态集合 a 转移到 b 转移到
$A$ ${6,4,7,0,2}$ $\varepsilon\text{-cl}({1,8}) = B$ $\varepsilon\text{-cl}({3}) = C$
$B$ ${1,5,4,7,0,2,8}$ $B$ ${3,5,4,7,0,2,9} = D$
$C$ ${3,5,4,7,0,2}$ $B$ $C$
$D$ ${3,5,4,7,0,2,9}$ $B$ ${3,5,4,7,0,2,10} = E$
$E$（含 10，终态） ${3,5,4,7,0,2,10}$ $B$ $C$

DFA 状态：${A, B, C, D, E}$，初态 $A$，终态 $E$。

(3) DFA 最小化

初始划分：${E}$（终态）、${A, B, C, D}$（非终态）

考察 ${A, B, C, D}$ 在 b 输入下的转移：

  • $A \xrightarrow{b} C$
  • $B \xrightarrow{b} D$
  • $C \xrightarrow{b} C$
  • $D \xrightarrow{b} E$（落入终态块）

$D$ 在 b 上行为不同（去到 $E$ 块），分出：${D}$、${A, B, C}$。

考察 ${A, B, C}$ 在 b 上：

  • $A \xrightarrow{b} C \in {A,B,C}$
  • $B \xrightarrow{b} D \in {D}$
  • $C \xrightarrow{b} C \in {A,B,C}$

$B$ 行为不同，分出：${B}$、${A, C}$。

考察 ${A, C}$ 在 a, b 上：

  • $A \xrightarrow{a} B$，$C \xrightarrow{a} B$（同块）
  • $A \xrightarrow{b} C$，$C \xrightarrow{b} C$（同块）

$A$、$C$ 等价，不可再分。

最小 DFA：4 个状态 ${A,C}$、${B}$、${D}$、${E}$，记为 $q_0, q_1, q_2, q_3$（$q_3$ 为终态）。

转移：

  • $q_0 \xrightarrow{a} q_1$，$q_0 \xrightarrow{b} q_0$
  • $q_1 \xrightarrow{a} q_1$，$q_1 \xrightarrow{b} q_2$
  • $q_2 \xrightarrow{a} q_1$，$q_2 \xrightarrow{b} q_3$
  • $q_3 \xrightarrow{a} q_1$，$q_3 \xrightarrow{b} q_0$

Tip 这种”$(a|b)^*abb$”是教科书经典例（Aho 龙书 3.7 节），最小 DFA 一定是 4 状态。如果你算出 5 个或 3 个，必有错。

Warning 子集构造时容易漏 ε 闭包：每次 move 之后必须再求一次 ε-closure，不能直接当 DFA 状态。
