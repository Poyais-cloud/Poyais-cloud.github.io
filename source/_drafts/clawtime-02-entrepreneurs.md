> **ClawTime 活动**，2026 年 5 月 16–17 日，广州南沙。
> 本篇整理自企业家圆桌分享环节，几位来自不同背景的创业者谈 AI 时代的一人公司、认知共生、以及人的定位。

---

这场圆桌的风格和 Hunter 的演讲完全不同。Hunter 是那种"我来讲我的手感"的人，而这几位企业家更像是在谈趋势、谈判断、谈"我们站在什么位置上"。

但有意思的是，他们说的东西和 Hunter 说的，其实是在回答同一个问题：**人到底在这个系统里扮演什么角色？**

---

## 一人公司：从"避税空壳"到"认知共生"

第一位分享者开门见山：一人公司（OTC）不是新鲜词。在美国早就有了，很多是为了避税；在中国互联网时代，也有人做独立开发、小型电商、虚拟产品。

但他说，今天的一人公司，和以前完全不同。

> 以前的一人公司，本质上是"把自己变成一个便宜的外包"。
>
> 今天的一人公司，是一个人 + N 个智能体。

他给了一个公式：

```
一人公司 = 人（掌握 Why）+ N 个智能体（掌握 How）
```

这个公式看起来简单，但他花了不少时间解释"Why"是什么。

他说，Why 有两层含义：

1. **Visa（知识）**：知道事情是怎么发生的——这是深层的 How
2. **Goal（目标）**：为什么要做这件事

人不能退出回路。AI 可以做 How，但 Why 必须由人来掌握。你需要知道目标，需要承担责任。

---

## 心智力：真正的工业革命

他用了一个类比，我觉得比我想象的更深刻。

第一次工业革命，人类第一次拥有了肌肉力量之外的"力气"——蒸汽机。

关键区别：
- **风车/水车**：依赖自然条件，无法随时部署
- **蒸汽机**：可随时部署，产生额外动力

他引用了乔布斯的一句话：

> "编程就像自行车。"

程序把程序员的知识固化下来，重复执行。它是一个工具，放大脑力，但不产生新的脑力。

**生成式 AI 才是蒸汽机。**

它替代了一部分原本必须用人类大脑做的事情。只要你给电，它就能产出。

他还提到了一个计量单位的转变：

| 时代 | 计量单位 |
|------|----------|
| 蒸汽机时代 | 马力 → 瓦特 |
| 前 AI 时代 | 人天 |
| AI 时代 | Token |

老板现在问的是："上了 AI 系统后，减少了多少人天消耗？"

未来可能变成："这个任务消耗了多少 token？"

---

## 人天 vs Token：一个根本性的转变

他说这个转变不只是计量方式的改变，而是**价值创造方式的改变**。

以前，一个任务必须用人天，因为你没办法让一只鸟来做，没办法让一只猩猩来做，也没办法让机器来做。即使你有程序员，程序也只是重复程序员写的东西——人天的投入是必不可少的。

但现在，只要你给模型电，它就能产出。这才是工业革命级别的变化。

他引用了一篇文章——《蒸汽、钢铁和无限心智力》，作者是 Evernote 的 CEO。文章的核心观点：AI 替代的是那些"原本不可能产生人天之外产出"的事情。

---

## AI 工程化的三阶段

他梳理了 AI 工程化的演进：

```
Context Window → Context + Tools → Context + Tools + Reasoning
```

这三个阶段是继承关系，不是替代关系。

- **Context Window**：模型能看多少内容
- **Context + Tools**：模型能调用工具
- **Context + Tools + Reasoning**：模型能推理和规划

他的判断：三年时间，我们走完了工业革命 150 年的路径——让每个人都能拥有自己的 AI 能力。

---

## 一人公司需要什么支持？

他列了五个要素：

### 1. Token 预算

第一个要解决的。他说好消息是国家正在建设计算网络，未来可能像买移动套餐一样买算力。

### 2. Harness 工具

小龙虾、Claude Code、其他 Agent 框架——这些工具让一人公司变得可行。

### 3. 产品化模板

他说虽然有了工具，但还没形成系统。成功的方向可以整理成模板，让后来者更快上手。

### 4. 分发渠道

互联网让虚拟产品可以快速触达用户。

### 5. 社区与空间

一人公司可以在家成立，但需要社区——交流经验、发现盲点、建立信任。

> **信任才是客户成功的关键。**

做生意本质上是两点：打信息差，积累信任。

---

## 人的进化：认知共生

另一位分享者提出了一个更大的视角。

如果放到几十万年的尺度看：

```
肌肉释放 → 工具使用 → 大脑共生
```

我们正在经历**认知的跃迁**。

他说，现在的竞争，选完智商卷体力，选完体力卷心力。心力变得越来越重要。

心力是什么？

- 内心稳定
- 清楚意义方向
- 能量管理

他说 AI 给你的是：

- 更广阔的视野
- 更强的决策优化
- 最强的运筹算法

就像航班排班——2000 多个复杂条件，人类算不过来，AI 可以秒出最优解。

> **人人都可以拥有认知智慧。**

以前读博士多年积累的东西，现在门槛降低、速度加快。这不是贬值，而是**普及**。

---

## 未来的嵌套世界

他描绘了一个有趣的图景：

```
人写 Agent → Agent 调用 Agent → Agent 调用人
```

智慧无边界，会不断嵌套。

> 一个 Agent 可能调用另一个 Agent，另一个 Agent 可能调用一堆人——因为最后一公里还是需要人。

这意味着：**人和 AI 的边界会越来越模糊**。不是 AI 替代人，而是人和 AI 互相嵌套，形成一个更大的智能系统。

---

## OTC 的自由是什么？

第一位分享者最后说了一段话，我觉得是这场圆桌的核心：

> OTC 的自由不是"不想打工"，而是**掌握自己的时间，掌握自己的劳动输出**。

以前，"地不到不为财"——你必须到场、必须动手、必须消耗人天。

现在，虚拟产品就可以创收，脑力工作可以交给 AI，人只需要掌握 Why。

但他说了一个警告：

> 人不能退出回路。你需要知道目标，需要承担责任。

如果你只是把 AI 当成"替你干活的东西"，你很快就会发现——你不知道它在干什么，你不知道它产出的东西是不是你想要的，你不知道出了问题该怎么修。

**OTC 不是躺平，是掌握。**

---

## 我的感悟

这场圆桌让我想到一个问题：**我到底想掌握什么？**

以前我会觉得，"掌握"意味着"我自己做"。但现在我开始意识到，"掌握"可能意味着"我知道它在做什么，我知道它为什么这么做，我知道它做出来的东西是不是我想要的"。

这和 Hunter 说的"Available Intelligence"其实是同一个道理。你不是要拥有一个理想的智能，你是要理解你手上的智能——然后知道怎么和它配合。

一人公司的公式"人 + N 个智能体"，看起来是技术问题，但其实是一个认知问题：**你能不能接受你不是唯一的智能来源？**

我觉得这是 AI 时代最难的转变。我们习惯了"我思考，我决策，我执行"。现在要变成"我思考，我决策，它执行——但我要知道它执行的是什么"。

这不是放弃控制，而是**重新定义控制**。
