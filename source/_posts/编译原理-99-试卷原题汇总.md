## 跨试卷高频题型对照

### 题型 1：构造文法描述给定语言

| 试卷 | 题号 | 语言 | 难度 |
|---|---|---|---|
| B | B·四·17 | $\{a^n b a^n \mid n \ge 0\}$ | ★★ |
| C | C·四·17 | $\{a^n b^n c^m \mid n\ge 1, m\ge 0\}$ | ★★★ |
| D | D·四·17 | $\{(ab)^n(cd)^m \mid n,m\ge 1\}$ | ★★ |
| E | E·四·17 | $\{a^i b^j \mid i>j\ge 0\}$ | ★★★★（不对称约束） |

**共性技巧**：先看是嵌套（中心嵌套用 $S\to aSa$）、还是连接（用 $S\to AB$ 拆两块）、还是不对称（用嵌套 + 外侧补差）。

---

### 题型 2：消左递归 / 提左公因子

| 试卷 | 题号 | 内容 |
|---|---|---|
| A | A·四·17 | 经典算术表达式消左递归 |
| B | B·五·18 | 提左公因子（短题） |
| C | C·五·18 | 消左递归 + 求 FIRST/FOLLOW |
| D | D·五·18 | 二义文法消左递归 + 提左公因子综合 |

**共性套路**：消左递归 → 提左公因子 → 求 FIRST → 求 FOLLOW → 构造 LL(1) 表 → 判 LL(1) 是否成立。这一整套流水线是 LL(1) 章节的"通关流程"。

---

### 题型 3：FIRST/FOLLOW + LL(1) 分析表

| 试卷 | 题号 | 文法 |
|---|---|---|
| A | A·五·18 | 经典算术表达式（消完左递归后） |
| B | B·六·19 | 悬挂 else 文法 |
| C | C·五·18 | 简化文法 $S\to Sa\mid b$ + $A\to Sc\mid d$ |

**共性技巧**：算 FIRST 时优先终结符直接得；算 FOLLOW 时记得开始符号必含 `#`、产生式末尾的非终结符 FOLLOW 要继承左部 FOLLOW。

---

### 题型 4：LR 项目集族 + SLR(1) 分析表

| 试卷 | 题号 | 文法 |
|---|---|---|
| A | A·六·19 | 经典算术（分析过程跟踪） |
| B | B·六·19 | 含括号嵌套文法 |
| C | C·六·19 | $S\to aA\mid bB$，$A\to cA\mid c$（LR(0) 不行 SLR 行） |
| E | E·六·20 | 二义文法 $E\to E+E\mid E*E\mid \ldots$（用优先级解冲突） |

**共性套路**：拓广文法 → 求 $I_0$ 闭包 → 逐个 GOTO 直到稳定 → 标出归约项目 → 用 FOLLOW 检查冲突 → 填表。

---

### 题型 5：四元组翻译

| 试卷 | 题号 | 内容 |
|---|---|---|
| A | A·六·19 | 算术表达式 |
| B | B·四·17 | 复杂算术表达式 |
| C | C·四·17 | while 循环 |
| D | D·四·18 | 布尔表达式短路 + 回填 |

**共性技巧**：算术 → 自底向上每个内部节点开一个 $t_i$；控制流 → 标记非终结符 $M$ 记位置 + 回填技术。

### 题型 6：词法（正则、NFA、DFA、最小化）

| 试卷 | 题号 | 内容 |
|---|---|---|
| A | A·一·4、A·二·11 | DFA/NFA 概念 + 正则识别 |
| B | B·一·3、B·一·5 | 词法分析任务 + 子集构造法 |
| C | C·三·15 | 词法分析功能简答 |
| D | D·三·15 | Thompson 构造 NFA |

**共性套路**：Thompson 构造每个算子有固定模板；NFA → DFA 用子集构造（每步求 ε 闭包）；最小化用划分法。

## 复习建议优先级

按出现频次和分值估计：

> **Note** 复习优先级
> 1. **★★★★★ 必拿分**：消左递归/提左公因子、FIRST/FOLLOW、LL(1) 表、SLR(1) 分析表、布尔表达式回填、if-then-else 与 while 翻译
> 2. **★★★★ 高频出**：构造文法描述语言、LR(0)→SLR(1) 升级、表达式翻译四元组、Thompson 构造 NFA
> 3. **★★★ 必看一遍**：DFA 最小化、TINY 扩展、二义文法 LR 处理、递归下降程序写法
> 4. **★★ 拿基础分**：编译过程概念题、中间代码形式选择题、符号表题、类型检查题
> 5. **★ 难题/送分**：矩阵连乘等开放题、固有二义性辨析
