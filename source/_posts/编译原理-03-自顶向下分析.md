## 1. FIRST 集

### SOP

> **Note** 求 FIRST 集
> 1. **终结符**：$\text{FIRST}(a) = \{a\}$
> 2. **空串**：$\text{FIRST}(\varepsilon) = \{\varepsilon\}$
> 3. **非终结符 $A$**：考察所有 $A \to X_1 X_2 \cdots X_n$
>    - 把 $\text{FIRST}(X_1) \setminus \{\varepsilon\}$ 加入 $\text{FIRST}(A)$
>    - 若 $\varepsilon \in \text{FIRST}(X_1)$，再把 $\text{FIRST}(X_2) \setminus \{\varepsilon\}$ 加入；以此类推
>    - 若所有 $X_i$ 都能推出 $\varepsilon$，则 $\varepsilon \in \text{FIRST}(A)$
> 4. **迭代到不动点**：所有 $\text{FIRST}$ 集不再变化为止

### 真题

#### [C·五·18]（接 02 文件，求 FIRST/FOLLOW 部分）
> 文法消左递归后为：
> $S \to bS'$，$S' \to aS' \mid \varepsilon$，$A \to Sc \mid d$
> 求各非终结符的 FIRST 集。

**解答**

- $\text{FIRST}(S')$：$aS'$ 给出 `a`；$\varepsilon$ 给出 `ε` → $\{a, \varepsilon\}$
- $\text{FIRST}(S)$：$bS'$ 给出 `b` → $\{b\}$
- $\text{FIRST}(A)$：$Sc$ 给出 $\text{FIRST}(S) = \{b\}$；$d$ 给出 `d` → $\{b, d\}$

$$
\boxed{\;\text{FIRST}(S)=\{b\},\quad \text{FIRST}(S')=\{a,\varepsilon\},\quad \text{FIRST}(A)=\{b,d\}\;}
$$

## 2. FOLLOW 集

### SOP

> **Note** 求 FOLLOW 集
> 1. **开始符号**：$\# \in \text{FOLLOW}(S)$（结束符）
> 2. **遍历每个产生式 $A \to \alpha B \beta$**：
>    - 把 $\text{FIRST}(\beta) \setminus \{\varepsilon\}$ 加入 $\text{FOLLOW}(B)$
> 3. **若 $\beta \Rightarrow^* \varepsilon$（即 $\varepsilon \in \text{FIRST}(\beta)$）或 $\beta$ 为空**：
>    - 把 $\text{FOLLOW}(A)$ 加入 $\text{FOLLOW}(B)$
> 4. **迭代到不动点**

> **Warning** **FOLLOW 集中绝不含 $\varepsilon$**！这是与 FIRST 集的关键区别。FOLLOW 集是"可能跟在某非终结符之后的终结符（含 #）"。

### 真题

#### [C·五·18]（续）
> 求 FOLLOW 集。

**解答**

初始：$\text{FOLLOW}(A) = \{\#\}$（$A$ 是开始符号？由题面看 $A$ 是包含 $S$ 的"较高层"。这里假设 $A$ 为开始符号；若 $S$ 为开始符号则需调整）。

按题意 $A$ 似乎是更高层（$A \to Sc$），但题目原文以 $S$ 开头。这里取 **$S$ 为开始符号**：

- $\text{FOLLOW}(S) = \{\#\}$
- 看 $A \to Sc$：$S$ 后跟 $c$ → $\text{FOLLOW}(S) \supseteq \{c\}$；但若 $A$ 不可达（$S$ 是开始符号、$A$ 不在 $S$ 推导链中），$A$ 实为冗余非终结符
- 此处假设题目实际给出的是文法 $\{A,S,S'\}$，**$A$ 为开始符**：
  - $\text{FOLLOW}(A) = \{\#\}$
  - $S \to bS'$：$S'$ 在 $S$ 末尾 → $\text{FOLLOW}(S') \supseteq \text{FOLLOW}(S)$
  - $S' \to aS'$：$S'$ 在末尾 → $\text{FOLLOW}(S') \supseteq \text{FOLLOW}(S')$（自身，无新增）
  - $A \to Sc$：$S$ 后跟 $c$ → $\text{FOLLOW}(S) \supseteq \{c\}$

迭代：
- $\text{FOLLOW}(S) = \{c\}$（无 $\#$，因为 $S$ 不是开始符号）
- $\text{FOLLOW}(S') = \text{FOLLOW}(S) = \{c\}$
- $\text{FOLLOW}(A) = \{\#\}$

$$
\boxed{\;\text{FOLLOW}(A)=\{\#\},\quad \text{FOLLOW}(S)=\{c\},\quad \text{FOLLOW}(S')=\{c\}\;}
$$

> **Tip** 题目若未明确开始符号，**默认第一条产生式左部为开始符号**。本题文法首条为 $S \to Sa \mid b$（消左递归前），故应**以 $S$ 为开始符号**重做：此时 $\text{FOLLOW}(S)=\{\#\}$、$\text{FOLLOW}(S')=\{\#\}$，$A$ 不可达可忽略。考试按题目实际开始符号判断，本节展示两种情形供对照。

## 3. LL(1) 文法判定与预测分析表

### LL(1) 判定条件

> **Note** 文法 $G$ 是 LL(1) 的充要条件
> 对每个非终结符 $A$ 的任意两条不同候选 $A \to \alpha$、$A \to \beta$：
> 1. **FIRST 不交**：$\text{FIRST}(\alpha) \cap \text{FIRST}(\beta) = \emptyset$
> 2. **若 $\beta \Rightarrow^* \varepsilon$**：$\text{FIRST}(\alpha) \cap \text{FOLLOW}(A) = \emptyset$
> 3. （等价说法）至多一条候选式可推出 $\varepsilon$

### 预测分析表构造 SOP

> **Note** 构造 LL(1) 分析表 $M[A, a]$
> 1. 对每条产生式 $A \to \alpha$：
>    - 对每个 $a \in \text{FIRST}(\alpha) \setminus \{\varepsilon\}$：填 $M[A, a] = A \to \alpha$
>    - 若 $\varepsilon \in \text{FIRST}(\alpha)$：对每个 $b \in \text{FOLLOW}(A)$，填 $M[A, b] = A \to \alpha$
> 2. **冲突 = 同一格子被多次填入** → 文法非 LL(1)

### 真题

#### [A·五·18]（10 分）LL(1) 综合
> 文法（已消左递归）：
> $E \to TE'$，$E' \to +TE' \mid \varepsilon$
> $T \to FT'$，$T' \to *FT' \mid \varepsilon$
> $F \to (E) \mid \text{id}$
> 求 FIRST、FOLLOW 集，构造 LL(1) 分析表，并判定是否 LL(1)。

**解答**

**Step 1：FIRST 集**

| 非终结符 | FIRST |
|---|---|
| $F$ | $\{(, \text{id}\}$ |
| $T'$ | $\{*, \varepsilon\}$ |
| $T$ | $\text{FIRST}(F) = \{(, \text{id}\}$ |
| $E'$ | $\{+, \varepsilon\}$ |
| $E$ | $\text{FIRST}(T) = \{(, \text{id}\}$ |

**Step 2：FOLLOW 集**

- $\text{FOLLOW}(E) = \{\#, )\}$（$\#$ 来自开始符号；$)$ 来自 $F\to(E)$）
- $\text{FOLLOW}(E') = \text{FOLLOW}(E) = \{\#, )\}$（$E'$ 在 $E\to TE'$ 末尾）
- $\text{FOLLOW}(T) = \text{FIRST}(E') \setminus \{\varepsilon\} \cup \text{FOLLOW}(E) \cup \text{FOLLOW}(E') = \{+, \#, )\}$
- $\text{FOLLOW}(T') = \text{FOLLOW}(T) = \{+, \#, )\}$
- $\text{FOLLOW}(F) = \text{FIRST}(T') \setminus \{\varepsilon\} \cup \text{FOLLOW}(T) \cup \text{FOLLOW}(T') = \{*, +, \#, )\}$

$$
\boxed{
\begin{aligned}
\text{FOLLOW}(E) &= \text{FOLLOW}(E') = \{\#, )\} \\
\text{FOLLOW}(T) &= \text{FOLLOW}(T') = \{+, \#, )\} \\
\text{FOLLOW}(F) &= \{*, +, \#, )\}
\end{aligned}
}
$$

**Step 3：LL(1) 分析表**

| | id | + | * | ( | ) | # |
|---|---|---|---|---|---|---|
| $E$ | $E\to TE'$ | | | $E\to TE'$ | | |
| $E'$ | | $E'\to +TE'$ | | | $E'\to\varepsilon$ | $E'\to\varepsilon$ |
| $T$ | $T\to FT'$ | | | $T\to FT'$ | | |
| $T'$ | | $T'\to\varepsilon$ | $T'\to *FT'$ | | $T'\to\varepsilon$ | $T'\to\varepsilon$ |
| $F$ | $F\to\text{id}$ | | | $F\to(E)$ | | |

**Step 4：判定**

每格至多一条产生式，**无冲突**，文法是 **LL(1)**。

> **Tip** 这是经典算术表达式文法，是 LL(1) 文法的标准范例。考试遇到一定要写到无误。

#### [B·六·19]（15 分）综合
> 文法 $S \to iEtS \mid iEtSeS \mid a$，$E \to b$。判断是否 LL(1)，若不是，改造之。

**解答**

**Step 1：判 LL(1)**

$S$ 的两条产生式 $iEtS$、$iEtSeS$ 都以 $i$ 开头：

$\text{FIRST}(iEtS) \cap \text{FIRST}(iEtSeS) = \{i\} \cap \{i\} = \{i\} \neq \emptyset$

**冲突**，**不是 LL(1)**（这正是悬挂 else 问题）。

**Step 2：提左公因子**

$S$ 两条候选共有前缀 $iEtS$：

$$
\begin{aligned}
S &\to iEtSS' \mid a \\
S' &\to eS \mid \varepsilon \\
E &\to b
\end{aligned}
$$

**Step 3：再判 LL(1)**

$S$：$\text{FIRST}(iEtSS') = \{i\}$，$\text{FIRST}(a) = \{a\}$，无交 ✓

$S'$：$\text{FIRST}(eS) = \{e\}$；$S' \to \varepsilon$ 需检查 $\text{FIRST}(eS) \cap \text{FOLLOW}(S')$：
- $S \to iEtSS'$：$S'$ 在末尾 → $\text{FOLLOW}(S') \supseteq \text{FOLLOW}(S) \supseteq \{\#, e\}$（$e$ 来自 $S' \to eS$ 中 $S$ 后？不，$S'$ 在 $iEtSS'$ 末尾。重看：$S' \to eS$ 中 $S$ 在末尾，$\text{FOLLOW}(S) \supseteq \text{FOLLOW}(S')$，循环）
- 实际：$\text{FOLLOW}(S) = \{\#, e\}$，$\text{FOLLOW}(S') = \{\#, e\}$
- $\text{FIRST}(eS) \cap \text{FOLLOW}(S') = \{e\} \cap \{e\} = \{e\}$ → **冲突仍在**！

> **Warning** **悬挂 else 是固有二义**问题。$M[S', e]$ 同时填 $S' \to eS$（else 配最近 if）和 $S' \to \varepsilon$（else 配上层 if），这两种语义都是合法的解析。

**Step 4：实际处理方式**

提完左公因子后，**约定 $M[S', e] = S' \to eS$**（else 与最近 if 配对，C/Java 都这么干），即在冲突格强制选移进式产生式，得到一个**带固定规则的 LL(1) 表**。

最终改造文法：

$$
\boxed{
\begin{aligned}
S &\to iEtSS' \mid a \\
S' &\to eS \mid \varepsilon \\
E &\to b
\end{aligned}
}
$$

附约定：$M[S', e]$ 取 $S' \to eS$。

## 4. 递归下降分析程序

### SOP

> **Note** 写递归下降程序
> 1. **每个非终结符 $A$ 写一个函数 $\text{parseA}()$**
> 2. **函数体内**：
>    - 看当前 token 在 $A$ 的哪条候选式 FIRST 集中
>    - 若选中 $A \to X_1 X_2 \cdots X_n$：
>      - 对每个 $X_i$：终结符就 `match()`（消耗当前 token），非终结符就调用对应函数
>    - 都不匹配且不能 ε 推 → 报错
> 3. **公共流程**：维护全局 `lookahead`（当前 token），`match(t)` 验证并前进

### 真题

#### [D·六·19]（15 分）递归下降
> 已知 LL(1) 文法（消左递归 + 提左公因子后）：
> $E \to TE'$，$E' \to +TE' \mid \varepsilon$
> $T \to FT'$，$T' \to *FT' \mid \varepsilon$
> $F \to (E) \mid \text{id}$
> 写出该文法的递归下降分析程序（伪代码）。

**解答**

```
token lookahead;          // 当前 token

void match(token t) {
    if (lookahead == t) lookahead = nextToken();
    else error("expected " + t);
}

void parseE() {
    parseT();
    parseE_prime();
}

void parseE_prime() {
    if (lookahead == '+') {
        match('+');
        parseT();
        parseE_prime();
    }
    // else: ε，什么都不做
}

void parseT() {
    parseF();
    parseT_prime();
}

void parseT_prime() {
    if (lookahead == '*') {
        match('*');
        parseF();
        parseT_prime();
    }
    // else: ε
}

void parseF() {
    if (lookahead == '(') {
        match('(');
        parseE();
        match(')');
    } else if (lookahead == 'id') {
        match('id');
    } else {
        error("expected ( or id");
    }
}

// 主程序
int main() {
    lookahead = nextToken();
    parseE();
    if (lookahead != '#') error("extra input");
}
```

> **Tip** 递归下降程序的"骨架"完全由 LL(1) 表决定：每个 if 分支对应该非终结符的一个候选式，分支条件对应该候选式的 FIRST 集（含 ε 推出时的 FOLLOW）。

## 5. 语法分析树与最左推导

### SOP

> **Note** 给定文法和句子，画语法树
> 1. **以开始符号为根**
> 2. **每应用一条产生式**，让左部非终结符长出对应的子节点序列
> 3. **保持顺序**：从左到右
> 4. **叶子全为终结符（或 ε）**

### 真题

#### [E·三·15]（5 分）画语法树
> 给文法 $E \to E+E \mid E*E \mid (E) \mid \text{id}$ 和句子 $\text{id} + \text{id} * \text{id}$，画两棵不同的语法树以说明文法的二义性。

**解答**

**树 1**（按 `+` 优先匹配 → $((id+id)*id)$ 语义）

```
        E
      / | \
     E  *  E
   / | \    |
  E  +  E  id
  |     |
  id   id
```

**树 2**（按 `*` 优先匹配 → $(id+(id*id))$ 语义）

```
        E
      / | \
     E  +  E
     |   / | \
     id E  *  E
        |     |
        id    id
```

两棵树都从同一句子推出，**文法二义**。

> **Tip** 二义性的标准证明就是"同一个句子两棵不同树"，画图比文字推导直观。

---

#### [E·三·16]（5 分）最左推导
> 用上题文法（二义文法）写出 $\text{id} + \text{id} * \text{id}$ 的两个不同最左推导。

**解答**

**最左推导 1**（对应树 1）：
$$E \Rightarrow E*E \Rightarrow E+E*E \Rightarrow \text{id}+E*E \Rightarrow \text{id}+\text{id}*E \Rightarrow \text{id}+\text{id}*\text{id}$$

**最左推导 2**（对应树 2）：
$$E \Rightarrow E+E \Rightarrow \text{id}+E \Rightarrow \text{id}+E*E \Rightarrow \text{id}+\text{id}*E \Rightarrow \text{id}+\text{id}*\text{id}$$

> **Warning** 注意：**两个最左推导不同 ↔ 两棵语法树不同**。这是判定二义性的另一等价方法。
